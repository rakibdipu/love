# 💖 Romantic Date Proposal & Interactive Planner App

An interactive, playful, and aesthetic web application designed to ask someone out on a date. Inspired by viral TikTok and GitHub proposal sites, this version combines all the best features into one seamless experience.

---

## ✨ Features Included

1. **💌 Secret Love Letter Opening:** Sweet envelope opener animation before popping the big question.
2. **🏃 The Legendary Runaway "NO" Button:**
   - Detects cursor proximity on desktop and flees in the opposite direction.
   - On mobile/touchscreens, it immediately darts away upon touch.
   - Safe viewport collision detection so it never gets lost outside the screen.
   - Changes into funny, dramatic pleading phrases on each attempt.
3. **📈 Self-Growing "YES" Button:**
   - Every time the user tries to hit "No", the "YES" button grows larger and more irresistible.
4. **🎉 Celebration & Confetti Burst:**
   - Multi-colored confetti, floating hearts, and victory sound effects when "YES" is clicked.
5. **📅 Multi-Step Dream Date Planner:**
   - **Step 1 (Date & Time):** Interactive calendar + time vibe selector (Morning Coffee, Lunch, Sunset Stroll, Candlelight Dinner, Stargazing).
   - **Step 2 (Food Selection):** Visual cards for Pizza, Kacchi Biryani, Burgers, Sushi & Ramen, Creamy Pasta, Fuchka, Ice Cream, etc.
   - **Step 3 (Activities):** Movie Date, Coffee & Long Talks, Arcade Games, Sunset Picnic, Late Night Drive, Painting, etc.
   - **Step 4 (Dress Code & Note):** Outfit vibes (Casual, Fancy, Cozy, Matching) + custom sweet note text box.
6. **🎟️ Official Romantic Date Pass / Ticket:**
   - Golden-pastel airline boarding pass style ticket with barcode, date, selected menu, itinerary, and seal of approval: `"ACCEPTED & NON-REFUNDABLE ❤️"`.
7. **📲 1-Click WhatsApp Send:**
   - Formats the entire itinerary with emojis and sends it straight to your WhatsApp number (`+8801734738311`).
8. **🌐 Bilingual & Audio:**
   - Switch anytime between **English** and **Banglish / বাংলা**.
   - Offline Web Audio API pop sounds, victory fanfare, and toggleable romantic lo-fi music.
9. **⚙️ In-App Settings Modal:**
   - Easily change Crush Name, Sender Name, and WhatsApp Number anytime.

## 🚀 How to Run Locally

Simply double-click `index.html` in your browser, or open it with Live Server in VS Code!

You can also run a quick local server using Python or Node:
```bash
# Python
python -m http.server 3000

# or Node npx
npx serve .
```
Then visit: `http://localhost:3000`

## 🌐 How to Host & Share Online (FREE)

### Option 1: GitHub Pages (Recommended)
1. Create a free GitHub repository (e.g. `date-proposal`).
2. Upload the files inside `love/`.
3. Go to **Settings > Pages**.
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. Your live link will be: `https://<your-username>.github.io/date-proposal/`
6. Send the link to your special someone! 💌

### Option 2: Vercel or Netlify
1. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Drag and drop the `love` folder.
3. It deploys in 5 seconds and gives you a free live link!
